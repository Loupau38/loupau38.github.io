Scenario Parameter Preset Import

The scenario parameter preset provides default values for the map generation settings and active game rules when creating a new game with it. It also points to a scenario, meaning that it is required to have a custom scenario parameter preset alongside a custom scenario for it to be useable ingame.

How To Use

Use one of the options above to load a scenario, then start editing it by navigating to the different tabs with the buttons at the top. Starting with the 'Config' tab is recommended.

Hover over elements to get more information on their purpose : buttons generally have a tooltip, text with a dotted underline means it has a tooltip.

Some inputs can be either in 'suggested value mode' or 'custom value mode'. The suggested value will be based on other values in the scenario, while the custom value will let you enter anything. Use the 💡/⚙️ button to switch between them.

This app use an autosave feature, hover over its setting in the top right and head to the 'Export' tab to know more.

      Autosave Clear

      You can remove the current locally saved scenario if you don't want it to show up the next time you use this app. The autosave is also automatically removed when you load a scenario from the 'Import' tab.
